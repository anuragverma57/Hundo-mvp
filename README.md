# Hundo Pizza — direct ordering app

Hundo's own ordering platform: customers order, outlets prepare, Hundo riders deliver, and admins
manage it all in one Next.js + Supabase app. It runs in **Demo Mode** (no paid services) until Hundo
approves the MVP.
